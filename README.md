# PONG

### This is a little pong game made in one afternoon with no AI using [raylib](https://github.com/raysan5/raylib).

## Compilation

The binary can be compiled with `make pong`. The game can be compiled and executed directly using `make run`.

In order to compile the executable, raylib's library should be installed.

## Controls

The players can be moved using **w** and **s** or using **up arrow** and **down arrow**.
